# engineering-process-monitor

## Учебный стенд мониторинга однопроходного процесса

Проект посвящён инженерной разработке аппаратно-программного стенда для наблюдения за безопасной моделью химико-технологического процесса.

Основная технологическая цепочка:

> верхняя ёмкость исходной жидкости → запорно-регулирующий элемент → линия подачи → фильтрационная колонка → измерительная точка на выходе → приёмная ёмкость

В базовой версии жидкость движется самотёком. Сорбционная очистка используется только как понятный модельный процесс в колонке; проект не предназначен для исследования или сравнения сорбентов.

## Текущий статус

Исправлены и согласуются документы этапов 1–4: границы проекта, постановка задачи, описание процесса, функциональная схема и концепция измерений. Физическая сборка не обязательна; допускаются проектные и демонстрационные данные.

Основные документы находятся в `docs/`, главный источник истины — `docs/project_scope.md`.

Будущая информационная архитектура: датчики или генератор данных → Arduino Uno или другой контроллер → USB или CSV → Python → Streamlit → графики, текущие значения, предупреждения и журнал событий.

Программная реализация на текущем шаге отсутствует. Ближайший этап после утверждения документации — подготовка графических технологической и функциональной схем.
