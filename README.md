# engineering-process-monitor

## Инженерный стенд мониторинга химико-технологического процесса

Учебный инженерный проект аппаратно-программного стенда для мониторинга параметров химико-технологического процесса.

В качестве модельного процесса используется сорбционная очистка окрашенного раствора.

## Текущий статус

Начальный этап проектирования.

В настоящее время создаётся структура проекта и подготавливаются материалы для последующей разработки технического задания.

Программная часть пока не реализована.
