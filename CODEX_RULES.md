# Правила работы Codex

1. Работать последовательно, небольшими проверяемыми этапами.
2. Не удалять существующие материалы без явного разрешения.
3. Перед изменениями изучать текущую структуру проекта.
4. Не начинать программирование до завершения постановки задачи и технического задания.
5. Объяснять выполненные изменения простыми словами.
6. Указывать назначение каждого нового файла.
7. Не добавлять ненужные зависимости и чрезмерно сложные технологии.
8. Отделять расчёты, документацию, электронику, программный код и материалы презентации.
9. После каждой задачи предоставлять способ проверки результата.
10. Все изменения выполнять в отдельной ветке и передавать на проверку через pull request.
