# Функциональная схема стенда

Статус: проектная схема без подтверждённой физической сборки.

## Функциональные блоки

| Блок | Назначение |
| --- | --- |
| Источник жидкости | Верхняя ёмкость создаёт запас и напор для самотёка |
| Регулирующий элемент | Запускает, останавливает и ограничивает поток |
| Линия жидкости | Соединяет технологические узлы |
| Фильтрационная колонка | Содержит модельную загрузку и формирует однопроходную стадию |
| Измерительные каналы | Получают температуру, pH, расход, уровень или объём, оптический показатель и статусы |
| Приёмная ёмкость | Собирает жидкость после колонки |
| Контроллер | Принимает доступные сигналы и передаёт данные |
| Генератор или CSV | Альтернативный источник демонстрационных данных |
| Python | Приём, проверка и обработка данных |
| Streamlit | Текущие значения, графики, предупреждения и журнал |
| CSV-хранилище | Локальное сохранение первичных и обработанных записей |

## Материальный поток

```text
[Верхняя ёмкость] → [Регулирующий элемент] → [Линия]
→ [Фильтрационная колонка] → [Измерительная точка]
→ [Приёмная ёмкость]
```

## Информационный поток

```text
[Датчики] ───────────────┐
                         ├→ [Контроллер] → [USB] ─┐
[Генератор данных / CSV] ┘                        ├→ [Python] → [Streamlit]
                                                  │             ├→ графики и значения
                                                  │             ├→ предупреждения
                                                  │             └→ журнал событий
                                                  └────────────→ [Локальный CSV]
```

Если физические датчики отсутствуют, соответствующие параметры не удаляются: источник помечается как ручной, расчётный, синтетический или CSV.

## Действия оператора

Оператор готовит стенд, запускает регистрацию, открывает и закрывает поток, наблюдает статусы, реагирует на предупреждения и завершает процесс. Автоматическое управление потоком не является обязательным.

## Границы

Мешалка и двигатель не входят в функциональную схему основной версии. Насос допустим только как отдельное будущее расширение. Электрические соединения и конкретные модели компонентов здесь не задаются.
