# Состояния процесса

## Общие состояния

| Состояние | Описание | Реакция интерфейса |
| --- | --- | --- |
| Процесс не запущен | регистрация и поток ещё не начаты | показать готовность источников |
| Нормальная работа | поток и доступные сигналы соответствуют будущим правилам | текущие значения и обычный журнал |
| Предупреждение | обнаружено отклонение, не требующее немедленной аварийной остановки | выделить причину и время |
| Аварийное состояние | риск пролива, переполнения или иного опасного развития | потребовать безопасной остановки оператором |
| Остановленный процесс | регулятор закрыт, поток завершён | завершить запись и сохранить итог |
| Потеря данных | ожидаемый сигнал или пакет отсутствует | не подставлять значение, записать событие |
| Частично недоступные измерения | один или несколько каналов недоступны, остальные работают | продолжить отображение доступных данных с явным статусом |

## Будущие правила обнаружения

- высокий расход;
- низкий расход;
- остановка потока;
- высокая температура;
- pH вне диапазона;
- переполнение приёмной ёмкости;
- ухудшение оптического показателя;
- потеря сигнала;
- зависание показаний;
- сильный шум.

Численные пороги сейчас не назначаются. Для каждого правила позже определяются источник, окно наблюдения, порог, задержка подтверждения, уровень важности и действие оператора. Простые правила являются основной версией; машинное обучение — только отдельное будущее расширение.
