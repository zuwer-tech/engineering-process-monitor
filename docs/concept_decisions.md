# Решения по концепции первой версии

## Зафиксированные решения

| Вопрос | Решение | Статус |
| --- | --- | --- |
| Объект | Настольная однопроходная установка с фильтрационной колонкой | обязательно |
| Технологическая цепочка | Верхняя ёмкость → регулятор → трубка → колонка → измерительная точка → приёмная ёмкость | обязательно |
| Подача | Самотёк | основная версия |
| Насос | Возможное будущее расширение | отложено |
| Модель процесса | Безопасная сорбционная очистка только внутри колонки | принято |
| Данные | Датчики, ручной ввод, синтетические данные или CSV | принято |
| Мониторинг | Температура, pH, расход, уровень или объём, оптика, время, статус сигналов | принято |
| Контроллер | Arduino Uno — кандидат, не подтверждённый окончательно | предварительно |
| Программа | Python и Streamlit, локальный Windows-запуск | выбрано для будущего этапа |
| Хранение | Локальный CSV, первичные и обработанные данные раздельно | принято |
| Аналитика | Простые правила и пороги | принято |

## Основная версия

В проект входят конструкция и крепления, две ёмкости, регулирующий элемент, линия жидкости, колонка, измерительные каналы, контроллер, компьютерная система, предупреждения и журнал событий.

В основную версию не входят перемешиваемый сосуд, обязательные мешалка и двигатель, внесение сорбента в ёмкость, исследование сорбентов, насосная подача, обязательная физическая сборка и машинное обучение.

## Проектный сценарий

Оператор заполняет верхнюю ёмкость, запускает регистрацию, открывает регулирующий элемент и наблюдает самотёчное прохождение жидкости через колонку. Параметры измеряются по ходу процесса и на выходе, жидкость поступает в приёмную ёмкость, после чего оператор закрывает поток и завершает регистрацию.

## Открытые вопросы

1. Требуемый расчётный расход и геометрия колонки.
2. Способы получения pH, расхода и уровня в MVP.
3. Размещение оптического и температурного каналов.
4. Материалы трубок, колонны, ёмкостей и креплений.
5. Численные пороги предупреждений после расчётов и выбора оборудования.
